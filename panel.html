关于 NotionHub

NotionHub —（扩展）— Python 端 v2.12.0。

把微信读书、Flomo、GitHub Stars、RSS、Douidian、Telegram Saved Messages、NetEase Music 等数据源通过插件方式接入 Notion 数据库。

  • 33 个内置插件：weread / flomo / github / rss / douban / telegram / netease / xiaoyuzhou / keep / toggl / forest / applemusic / douyin / youtube / gutu / trakt / dayone / ticktick / duolingo / bilibili / beidanci / spotify / strava / weibo / xiaohongshu / jike / podcast / applepodcast / daily / daily-weather / daily-location / guwendao / fix。
  • Python CLI 由 pip install -e . 安装，提供 notionhub / weread2notion 命令。
  • 自托管 GitHub Actions 自动同步：.github/workflows/weread.yml（微信读书）与 sync.yml（其余数据源，一条 plugins sync --all 覆盖）。无需 notionhub-runner 云端仓库。
  • 扩展只与 https://api.notion.com/* 通信，Token 仅存在本机 chrome.storage.local。
